# 设计师 / 功能指南（2026-11-23 Cycle 5）

## 功能定位

`!rtd list` 是“目录/检索”，不是新的抽骰入口：

- 只读，不触发抽骰、不改冷却、不改持有状态。
- 数据来自当前 `_dices`（已启用）与 `DiceUi` 的稀有度/名称/描述。
- 输出分三种模式：总览、按稀有度、按关键词。

## 交互设计

- 总览先给数量和分布，再给用法，避免一屏 171 行。
- 按稀有度列出时最多 24 个，每行 4 个；超出时提示剩余数量并引导搜索。
- 关键词搜索最多 8 条详细行；每条复用 `!rtd status` 的骰子行格式。
- 已持有用绿色 `✓` 标在名字后，不改变名称本身。
- 稀有度别名同时接受中文和英文，大小写不敏感。

## 边界

- 不新增配置 Key，不写玩家存档。
- 不把 `!rtd list` 做成菜单，不引入分页状态。
- 不修改 `DiceBlueprint.CanBeDrawn` / 抽骰池 / 权重。
- 不做“按 Dice 名直接抽骰”；那会改变玩法与平衡。

## 验收

- 三个模式输出长度可控。
- 搜索匹配规则单一、可预测。
- 所有新文案走 `lang/en.json`，不散落硬编码。
