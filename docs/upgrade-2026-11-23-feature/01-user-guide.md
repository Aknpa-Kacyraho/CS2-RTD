# 用户 / 管理员功能指南（2026-11-23 Cycle 5）

## 目标

给玩家一个只读的骰子目录：不用记住 171 个类名，也能知道当前有哪些骰子、自己是否已经持有、某个关键词对应什么效果。

## 新功能

- `!rtd list`：显示可用骰子总数，以及传说/组合/史诗/稀有/普通各有多少个，并给出用法。
- `!rtd list 传说`（或 `legendary`）：列出该稀有度的骰子名；已持有的骰子带 `✓`。
- `!rtd list <关键词>`：按中文名或英文类名搜索，显示最多 8 条“名称 [稀有度] — 效果”。
- `!rtd help` 增加 `!rtd list` 一行。

## 不会变化

- 抽骰概率、冷却、伤害、持续时间、Dice 效果、`!givedice`、TAB 名称、Combo 规则。
- `!rtd` 无参数仍然抽骰；`!rtd list` 是唯一新增子命令。
- 未知子命令仍然只打印帮助，不会误抽骰。

## 验收

- `!rtd list` 数量与当前启用 Dice 一致。
- 稀有度别名中英文都能用。
- 搜索中文名、英文类名、大小写混合都能命中。
- 超过显示上限时有明确提示，不静默截断。
- 已持有标记只在当前回合持有该 Dice 时出现。
