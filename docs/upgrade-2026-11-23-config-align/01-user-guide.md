# 用户 / 管理员配置对齐指南（2026-11-23 Cycle 9）

## 目标

让插件“预检查的配置文件”和 CounterStrikeSharp 实际重载的配置文件完全一致，避免两种少见但难查的情况：

- 预检查读取了另一个路径，真正重载的文件却没检查。
- 预检查用的 JSON 规则比 CSS 宽松，检查通过后 CSS 仍报错。

## 你会看到的变化

- `!rtd reload` 的预检查改用 CSS 同款 JSON 规则：
  - 允许 `//` 注释。
  - 不允许尾逗号（CSS 也不允许）。
  - 属性名大小写按 CSS 规则处理。
- 预检查路径改为 `Config.GetConfigPath()`，与 CSS Reload 读取的文件一致。
- 地图 overlay 读取也使用同一路径，避免服务器目录/插件目录改名后读错文件。
- 错误信息仍会在聊天/控制台提示，旧配置保持生效。

## 不会变化

- 配置 Key、默认值、Dice 数值、命令、TAB/Combo。
- JSON 注释仍然可用。
- TOML 配置不会被 JSON 预检查误判（检测到 `.toml` 时跳过 JSON 校验，交给 CSS）。

## 验收

- 带注释的 JSON 仍可加载。
- 带尾逗号的 JSON 会在预检查阶段被拒绝。
- 真实部署的 `RollTheDice.json` 能通过预检查。
- 改插件目录名不会导致预检查读错文件。
- 未实机验证前，不宣称“所有配置错误都已覆盖”。
