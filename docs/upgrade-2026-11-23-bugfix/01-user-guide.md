# 用户 / 服务器管理员升级指南（2026-11-23）

## 目标

优先消除玩家可感知的稳定性问题，不改变骰子概率、冷却、伤害和命令。

## 重点问题

1. **断线重连后状态残留**
   - 玩家被冻结、无敌、加速或血量异常时断线，重连后可能继承旧状态。
   - 当前已清理 Invulnerability/MoveLock/StackingHealth/StackingBonus；部分生命值 Dice 的按玩家字典仍要等 `Reset`。

2. **多个效果同时修改移动状态**
   - Amber/Fate/Phoenix/Skyline 仍有直接写 MoveType 的路径。
   - 与 IceBeam/Titanfall 等同时作用时，可能出现移动恢复错误。

3. **配置热重载**
   - 类型错误时可能留下部分更新；地图配置 fallback 仍可能静默忽略覆盖。
   - 管理员改配置后要查看日志，不要只看“命令成功”。

4. **高负载**
   - 20 人混战、频繁伤害、频繁按 E 时，存在 171 Dice 全量扫描。
   - 目前没有实机 profiling，不能仅凭静态分析判断卡顿程度。

## 验收标准

- 断线/重连：不继承冻结、加速、无敌、血量上限。
- 回合结束/换图：无残留实体、Timer、Buff。
- 配置 Reload：成功/失败都有明确日志；坏配置不覆盖旧配置。
- `!rtd`、`!rtd status`、`!rtd tab`、`!givedice` 行为不变。
- 改动后至少完成：构建、配置测试、架构检查、实机断线/换图回归。

## 非目标

- 不重做 Dice 平衡。
- 不改变 Combo 名称、冷却、伤害。
- 不为了“更整洁”重写全部 Dice。
