# 用户 / 管理员配置原子重载指南（2026-11-23 Cycle 13）

## 目标

让 JSON 配置重载变成“全有或全无”：如果应用过程中某个属性 setter 抛异常，已改的属性会回滚，旧配置继续生效。

## 你会看到的变化

- `!rtd reload` 对 JSON 配置：
  - 先完整反序列化；
  - 再原子应用到当前配置；
  - 中途失败会回滚并提示错误；
  - 不会留下“前几个字段已改、后几个字段没改”的半套配置。
- 非法 JSON / 类型错误仍然在应用前失败，旧配置保持。
- 注释、尾逗号、大小写规则与 CSS 保持一致。
- TOML 配置仍走 CSS 原生 Reload（本轮不写 TOML 解析器）。

## 不会变化

- 配置 Key、默认值、Dice 数值、命令、播报、TAB、Combo。
- 配置路径与 CSS 一致（`Config.GetConfigPath()`）。
- 重载不会把内存配置写回磁盘。

## 验收

- 正常 JSON 重载成功。
- 类型错误失败且旧配置不变。
- setter 抛异常时已应用字段回滚。
- TOML 仍能通过 CSS Reload。
- 未实机验证前，不宣称“配置系统零风险”。
