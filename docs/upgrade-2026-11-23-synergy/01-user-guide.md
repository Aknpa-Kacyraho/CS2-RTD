# 用户 / 管理员 Dice 联动优化指南（2026-11-23 Cycle 10）

## 目标

让 Combo（Dice 联动）在玩家多、Dice 多的局面下更省、更准、更好读，同时不改任何联动数值。

## 你会看到的变化

- Combo 公告里的玩家名不再带 TAB 的 `[Dice]` 前缀，显示真名。
- Combo 检查不再每次重新枚举全服玩家，减少高玩家数下的无谓开销。
- 没有 Dice 需要 `OnDiceSetChanged` 时，联动刷新不再空跑 171 个 Dice。
- 启动时新增 Combo 数据校验：自联动、重复配对、空显示名会被指出。

## 不会变化

- 68 个 Combo 的触发条件、效果、数值、公告文案。
- Dice 概率、冷却、伤害、持续时间、奖励。
- TAB 联动标签的规则（仍然按现有 `ResolveComboNames` 展示）。
- 配置 Key、命令。

## 验收

- Combo 仍能正常触发，公告里没有 `[Dice]` 前缀。
- 同一 Combo 的公告内容与旧版一致，只是玩家名更干净。
- 高玩家数下 Combo 检查不再产生 `Utilities.GetPlayers()` 临时列表。
- 启动日志没有新增 Combo 数据警告（当前数据应全部通过）。
- 未实机验证前，不宣称“联动零 Bug”。
