# 用户 / 管理员全面进化指南（2026-11-23 Cycle 8）

## 目标

把“飞行/虚无/冻结/漂浮”等临时移动状态收口到同一套命名作用域，避免一个效果结束后把另一个效果覆盖成步行，或死亡/移除 Dice 后把 noclip 留到重生。

## 玩家可能感受到的变化

- 天际（Skyline）飞行结束、虚无（Void）结束，会恢复到进入前的移动状态，而不是无条件变回步行。
- 同时存在多个移动效果时，最后激活的效果优先；先结束的效果不会把后面的效果顶掉。
- 死亡、`!givedice` 替换、回合结束会正确释放对应的移动作用域，减少“重生还在飞/还在虚无”的残留。
- `!rtd_health` 增加 `move_locks=keys/players`，管理员能看到当前移动锁数量。

## 不会变化

- 天际飞行时长、冷却、按键、零后坐联动。
- 虚无时长、冷却、无敌/隐身/飞行表现。
- 琥珀冻结概率/时长、凤凰涅槃时长/爆炸/奖励。
- 抽骰概率、伤害、命令、配置 Key。

## 验收

- 天际飞行结束回到飞行前状态。
- 虚无结束回到虚无前状态。
- 两个效果重叠时，后激活者优先；先结束者不覆盖后者。
- 死亡/移除/换图后没有残留 noclip 或移动锁。
- 未实机验证前，不宣称“全部移动状态已零残留”。
