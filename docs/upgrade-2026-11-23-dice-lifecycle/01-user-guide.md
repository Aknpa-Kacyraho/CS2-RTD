# 用户 / 管理员 Dice 生命周期指南（2026-11-23 Cycle 6）

## 目标

让老 Dice 和新 Dice 在“玩家断线、控制器失效、回合结束”时表现一致：该拆的光效拆掉，该解的冻结解开，该清的状态清掉。

## 玩家可能感受到的变化

- 断线重连后，旧回合的琥珀冻结、凤凰光翼/光晕、临时移速/血量状态更不容易残留。
- `!givedice` 替换 Dice、死亡移除 Dice 时，琥珀冻结会立即解除，而不是等计时结束。
- 正常抽骰、伤害、冷却、持续时间不变。

## 不会变化

- Dice 概率、权重、伤害数值、持续时间、命令、配置 Key。
- Phoenix 的 10 秒涅槃、爆炸、444HP/护甲/AK 奖励。
- 琥珀的冻结概率与冻结时长。
- TAB 名称、Combo 规则、`!rtd list`。

## 验收

- 断线/重连后不再看到旧光翼、旧光晕或持续冻结。
- 回合结束/换图/`css_reload` 后没有 Phoenix/Amber 残留。
- 正常玩一局，Phoenix 与 Amber 的触发、结束、死亡清除与 v1.4.7 一致。
- 未实机验证前，不宣称“已修复全部残留”。
