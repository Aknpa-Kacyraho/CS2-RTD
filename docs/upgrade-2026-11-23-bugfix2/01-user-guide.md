# 用户 / 管理员 Bug 修复指南（2026-11-23 Cycle 7）

## 目标

修三个会直接影响管理员操作或回合状态的 bug，不改变任何 Dice 玩法数值。

## 修复内容

- **配置重载类型错误**：`RollTheDice.json` 里把 `true` 写成 `"yes"`、把数字写成字符串等，重载会在改内存前被拒绝，旧配置保持生效，并在聊天/控制台报错。
- **`!givedice` 无参数列表**：以前 0 参数会被命令框架拦下，列表分支实际不可达；现在 `!givedice` 会显示可用 Dice（中文名 + 类名、三列、带数量）。
- **自动抽骰空池保护**：当没有可抽取 Dice 时，自动抽骰不再先移除玩家现有 Dice；避免“抽不到但旧 Dice 没了”。

## 不会变化

- 抽骰概率、权重、冷却、伤害、持续时间、奖励、命令参数语义。
- `!givedice <玩家> [dice]` 的正常行为。
- 配置 Key 与默认值。
- `!rtd list`、TAB、Combo。

## 验收

- 改坏类型后 `!rtd reload`（或对应重载命令）失败，旧配置仍可用。
- `!givedice` 0 参数能列出 Dice；`!givedice <玩家>` 仍随机给一个。
- 无可抽 Dice 时自动抽骰不删旧 Dice。
- 未实机验证前，不宣称“已修复全部配置问题”。
