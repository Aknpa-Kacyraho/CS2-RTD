# 用户 / 服务器管理员 Dice 设计指南（2026-11-23 Cycle 3）

## 目标

让 Dice 的名称、配置、稀有度、Combo、文档保持一致，同时不改变玩家实际抽到的 Dice 行为。

## 用户可见影响

- 抽骰概率、冷却、伤害、效果持续时间、命令均不变。
- Dice 名称、TAB 前缀、Combo 名称不变。
- 本轮只增加启动时只读校验和 `!rtd_health` 摘要。

## 验收

- `!rtd`、`!givedice`、`!rtd status` 与 1.4.4 一致。
- 启动日志能指出缺失配置/名称/稀有度的 Dice。
- 不因某个 Dice 元数据错误而卸载插件或禁用其他 Dice。
