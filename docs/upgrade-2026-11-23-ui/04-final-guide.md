# 统一 UI 指南（Cycle 4 / v1.4.6）

## 目标

在不改变玩法、命令语义和配置的前提下，把命令面板的排版与颜色收口到 `DiceUi`，让玩家和管理员更快读懂信息。

## 本轮范围

1. 新增 `RollTheDice/DiceUi.cs`：稀有度标签/颜色/排序权重、Dice 名称/描述、骰子行、分列工具。
2. `!rtd help` 追加一行提示，保留原命令顺序。
3. `!rtd status` 按稀有度降序，标题显示数量，骰子行统一由 `DiceUi` 生成。
4. `!givedice` 无参数列表改为“中文名（类名）”、三列、带数量标题。
5. `!rtd_health` 拆为四行诊断。
6. 新增 3 个本地化 key；不修改既有 key 的语义。
7. 版本升到 v1.4.6，更新 CHANGELOG/README/自检。

## 明确不做

- 不改抽骰概率、冷却、伤害、持续时间、Dice 效果或命令参数。
- 不新增玩家命令，不改 `!rtd` 子命令解析。
- 不改 TAB 名称、Combo 规则、Dice 特效。
- 不重构 Dice 内部的 335 处聊天/中心提示。
- 不改配置格式，不引入主题文件。

## 验收门槛

- 构建 0 warning / 0 error。
- 配置测试 32/32；Registry + UI 测试全过。
- 架构检查通过，`timers=0`，主类不超 2900 行。
- `!rtd help/status`、`!givedice`、`!rtd_health` 人工走查无异常。
- 稀有度颜色与 v1.4.5 一致。

## 自检

- 用户：命令是否仍好用，信息是否更清楚。
- 设计师：视觉语言是否统一，是否过度设计。
- 工程师：构建/测试/架构/CI 是否通过，是否引入重复实现。
