# 用户 / 管理员 UI 指南（2026-11-23 Cycle 4）

## 目标

让玩家和管理员在聊天框里更快看懂信息，不改变任何玩法。

## 玩家会看到的变化

- `!rtd help` 增加一行提示，命令列表保持原有顺序与含义。
- `!rtd status` 的骰子按稀有度排序，标题显示当前数量，每行仍是“名称 [稀有度] — 效果”。
- 抽骰结果、冷却、自动抽骰、TAB 开关等提示文字不变。
- `!givedice` 不带参数时，Dice 列表改为三列排版，显示“中文名（类名）”，不再是 171 行单列英文类名。
- `!rtd_health` 改为多行诊断，管理员更容易扫读。

## 不会变化

- 抽骰概率、冷却、伤害、持续时间、Dice 效果、命令参数、配置 Key。
- `!rtd`、`!rtd auto`、`!rtd tab`、`!rtd status`、`!givedice` 的行为。
- TAB 名称与 Combo 显示规则。

## 验收

- 所有命令仍可执行，未知子命令仍只打印帮助。
- `!rtd status` 无骰子时仍显示原来的“还没有骰子”提示。
- `!givedice` 列表完整覆盖所有已启用 Dice，名字可读。
- 聊天行宽在 1080p 下不明显折行。
