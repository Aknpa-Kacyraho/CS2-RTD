# 用户 / 管理员架构升级指南（2026-11-23 Cycle 2）

## 目标

把 TAB 名称相关状态从主类移出，降低主类复杂度，但不改变玩家看到的名称。

## 用户可见行为必须保持

- `!rtd tab` 开关行为不变。
- `!rtd` 抽骰、`!givedice`、移除骰子后的 TAB 前缀不变。
- Combo 队友标签、`[A]+2 名字` 压缩格式不变。
- 回合结束恢复真名、断线清理、换图清理不变。
- 真实 `[CLAN]` 前缀不能被误删。

## 验收

- `!rtd tab` 开/关后 TAB 名称与升级前一致。
- 抽到/移除 dice 后 1 秒内名称刷新一致。
- 回合结束真名恢复。
- 断线重连不残留旧 dice 前缀。
- 换图/热重载后无旧名称 Timer。
