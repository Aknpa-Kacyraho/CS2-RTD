# 用户 / 管理员 Dice 设计指南（2026-11-23 Cycle 12）

## 目标

让 TAB 名字里的 Combo 标签更完整：一个 Dice 同时参与多个联动时，不再只显示第一个命中的 Combo。

## 你会看到的变化

- 例如同时拥有 `Adrenaline + Berserker + Overheat` 时：
  - 旧版只显示「狂暴血脉」，`狂热` 被吞掉；
  - 新版同时显示「狂暴血脉」和「狂热」。
- 没有参与任何 Combo 的 Dice 仍保留在 TAB 标签里。
- Combo 标签仍然按现有 `[A] [B] 名字` / `[A]+N 名字` 压缩，不会无限变长。

## 不会变化

- 68 个 Combo 的配对、名称、效果、数值、触发条件。
- Dice 概率、冷却、伤害、持续时间、奖励。
- TAB 名字的格式与 `!rtd tab` 开关。
- 配置 Key、命令、播报。

## 验收

- 共享 Dice 的多个 Combo 能同时出现。
- 独立 Dice 不会被误删。
- 没有 Combo 的玩家标签不变。
- 未实机验证前，不宣称“所有联动展示已完美”。
