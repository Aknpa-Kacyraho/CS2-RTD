# 用户 / 管理员 Dice 播报优化指南（2026-11-23 Cycle 11）

## 目标

让抽到 Dice 时的聊天与屏幕中央 HUD 使用同一套本地化描述，显示真名，并且不会被描述里的 `<`、`&` 等字符破坏排版。

## 你会看到的变化

- 抽到 Dice 的中央 HUD 描述改为与 `!rtd status` 一致的本地化 `_player` 文本，不再出现英文/`Unknown Dice`/过期描述。
- HUD 里的 Dice 名、稀有度、描述、特效文本会做 HTML 编码，`&`、`<`、`>` 不再破坏版面。
- 传说/组合 Dice 的全服播报使用真名，不再带 TAB 的 `[Dice]` 前缀。
- 聊天里的“你抽到了 [稀有度] 名称”保持不变。

## 不会变化

- 抽骰概率、稀有度、Dice 效果、持续时间、冷却、奖励。
- `!rtd status`、`!rtd list`、TAB 名称、Combo 触发。
- 播报音效、全服播报开关、HUD 开关。
- Dice 自身 `NotifyPlayers` 的聊天/中央提示层级（本轮未合并）。

## 验收

- HUD 描述与 `!rtd status` 的中文效果一致。
- 描述含 `&`/`<` 时 HUD 仍正常。
- 传说播报显示真名。
- HUD 关闭时行为与旧版一致（不发送 reveal HUD）。
- 未实机验证前，不宣称“播报零问题”。
